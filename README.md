## Git Workflow & History
- **Atomic Commits**: Commits are structured logically around core capability areas (App -> IaC -> CI/CD -> K8s -> Reliability -> Docs).
- **Conventional Commit Standard**: Structured using `feat`, `ci`, `infra`, `test`, and `docs` prefixes for automated readability.
- **Traceability**: All major decisions and pipeline triggers map directly to discrete functional commits.
